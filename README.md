# Təhsil — korporativ sayt

Tədris mərkəzi üçün statik korporativ sayt (HTML + CSS + JS, build tələb etmir).

## Fayllar
- `index.html` — səhifənin strukturu və mətnlər
- `styles.css` — dizayn
- `script.js` — menyu, animasiyalar, forma

## Deploy
`main` branch-a hər push Vercel tərəfindən avtomatik deploy olunur.
